# 하드웨어

## 부품

| 부품               | 권장                                                              | 비고                                                                                                                       |
| ------------------ | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 컴퓨터             | **Raspberry Pi 4 (2GB 이상)** 또는 Pi 5                           | 내장 Wi-Fi로 AP를 만듭니다. 5GHz 지원 필요                                                                                 |
| CarPlay 동글       | **Carlinkit CPC200-CCPA** 계열 (USB ID `1314:1520` / `1314:1521`) | 유선 CarPlay를 무선으로 바꿔 주는 동글 중 node-carplay가 지원하는 모델                                                     |
| 저장장치           | microSD 16GB 이상 (A1 등급 이상)                                  | Raspberry Pi OS Lite 64-bit (Bookworm)                                                                                     |
| 전원               | 테슬라 USB-C 포트 → USB-C 케이블                                  | Pi 4는 5V/3A, Pi 5는 5V/5A 권장. 테슬라 USB-C는 차량·연식마다 출력이 다르므로 저전압 경고(`vcgencmd get_throttled`)를 확인 |
| 케이블             | USB-A(또는 C) ↔ 동글 케이블                                       | 동글 동봉품 사용                                                                                                           |
| (선택) 케이스·쿨러 | 방열 케이스                                                       | 여름철 차량 실내 온도 대비                                                                                                 |
| (선택) USB 마이크  |                                                                   | Siri/통화용 (로드맵 4단계)                                                                                                 |

## 연결

```
테슬라 USB-C ──전원──▶ Raspberry Pi ──USB──▶ Carlinkit 동글
                         │ (내장 Wi-Fi AP)          ▲
                         ▼                          │ 무선 CarPlay
                    테슬라 브라우저                  iPhone
```

- 동글은 Pi의 USB 포트에 꽂습니다. 아이폰은 동글과 무선으로 연결되므로 차 안 어디에 있어도 됩니다.
- Pi와 동글은 글로브박스나 센터 콘솔 수납함에 둘 수 있습니다. 금속 구조물이 Wi-Fi를 가리지 않는지 확인하세요.

## 전원과 수명

- 테슬라는 주차 후 일정 시간이 지나면 USB 전원을 끕니다. Pi가 갑자기 꺼져도 SD카드가 손상되지 않도록,
  안정화 후에는 **읽기 전용 루트 파일시스템**(`raspi-config` › Performance › Overlay File System)을 권장합니다.
- '캠프 모드'나 '실내 온도 유지'를 켜 두면 USB 전원이 유지되어 Pi가 계속 켜져 있을 수 있습니다.

## 처음 페어링

1. Pi에 설치 스크립트를 실행하고([README](../README.md#라즈베리파이에-설치)) 동글을 꽂습니다.
2. 아이폰 **설정 › 일반 › CarPlay**에서 동글(이름: `TeslaMediator`)을 선택합니다. 블루투스 페어링 요청이 뜨면 승인합니다.
3. 다음부터는 차에 타면 자동으로 연결됩니다.
